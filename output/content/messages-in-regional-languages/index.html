A note on the data

A language guide, not a census ranking

Our directory brings together names of languages, regional varieties, and local speech traditions. Showing a language under a state means the inventory associates it with that region; it does not mean everyone there speaks it.

Editorial priorities P1/P2/P3 indicate which topics to cover first, not population, official status, or vitality. Some entries represent umbrella or community designations. Native names and script recommendations can be incomplete; confirm text with local fluent speakers before publication.

This edition is dated 30 October 2026. It is an exploratory, human-review-required working dataset rather than a row-verified language census.

For researchers & writers

Use the data responsibly

  • Search by state, language, local area, script, or alternative name.
  • Use “Content writer mode” for stable IDs and review cues.
  • Export only the records selected by your current filters.
  • Check local spellings, script, and festival relevance before publishing.
